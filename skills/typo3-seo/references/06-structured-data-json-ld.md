# 6. Structured-data routing

Page-type selection, schema.org entity graphs, JSON-LD implementation, Rich Results Test evidence,
and `brotkrueml/schema` integration are owned by
[`typo3-structured-data`](../../typo3-structured-data/SKILL.md).

Use `typo3-seo` only for the canonical URLs, hreflang, metadata, sitemap, robots rules, and indexing
conditions that the entity graph consumes. Do not keep a second JSON-LD recipe here; duplicated
guidance is how incompatible generators and stale consumer claims return.
