# P09 — Rung 14.3 execution (stateful iterations in loop 100)

Track `invariance`. The upgrade itself.

## Preconditions
P08 migration findings closed. Take a fresh snapshot immediately before each stateful command group.

## Steps
1. `ddev typo3 extension:setup` — the Core command that creates tables/fields and applies add/change
   schema operations. A stale obsolete `NOT NULL` column can block this command or the first runtime
   write; resolve that exact, evidenced blocker from the fresh snapshot instead of repeatedly retrying
   a half-migrated database.
2. Immediately review the **remaining** schema comparison in the backend database analyzer in Admin
   Tools. `database:updateschema "*.add,*.change" --dry-run` is an additional preview **only** where
   the project already ships `helhum/typo3-console`; that command is not Core. Review all eight
   operation classes and prove data/workspace safety before prefix/drop cleanup per
   `references/database-integrity.md`. Do not describe this as pre-approval for step 1: Core has
   already applied its non-destructive setup operations.
3. `ddev typo3 upgrade:list`, then the reviewed `upgrade:run` steps.
4. Re-run `site:list`, `site:show <site-identifier>`, `site:sets:list` and `ddev exec locale -a`;
   block on an unavailable locale, selected set or set dependency. Then run `referenceindex:update`,
   `language:update`, `cache:flush` and `cache:warmup`.
5. Log in to the backend at the DDEV URL. Inspect Admin Tools environment and upgrade status,
   the database analyzer state, and the remaining wizard list once after the command group.
   Return remaining root causes to the parent graph for a bounded recovery; do not start a nested
   cleanup programme. The exit still requires clean evidence.

## The warm-up deprecation is not noise
Cache warm-up must not emit the #108345 package-metadata deprecation. When it does, fix the
extension's `composer.json` (`version` / `providesPackages`) rather than ignoring the message — v15
stops evaluating `ext_emconf.php` entirely, and this is the warning that the metadata is not where it
needs to be.

## Exit
Schema comparison clean. Every wizard run, or consciously skipped with a recorded reason. Reference
index and relation checks recorded. Warm-up emits no #108345 deprecation.

## Blocking
Any failure — restore the operation's snapshot, fix the cause, and record a new parent iteration.
Never continue on a half-migrated database and never hide retries inside a nested tool loop.
